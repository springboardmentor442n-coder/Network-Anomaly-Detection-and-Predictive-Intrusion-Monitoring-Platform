# NetShield AI UI and Application Workflow

## Application Screens

### 1. Login Page

Allows registered users to securely access the NetShield AI platform.

Main elements:

- Email input
- Password input
- Login button

### 2. Dashboard

Provides a centralized overview of network monitoring and security activity.

Main elements:

- Network traffic summary
- Security event summary
- Active alerts
- System status
- Recent activity

### 3. Traffic Monitoring Page

Allows users to view and monitor network traffic information.

Main elements:

- Traffic records
- Source information
- Destination information
- Protocol information
- Timestamp

### 4. Alerts Page

Displays detected security events and alerts.

Main elements:

- Alert information
- Threat type
- Severity level
- Alert status
- Timestamp

### 5. User Profile

Allows users to view basic account information.
