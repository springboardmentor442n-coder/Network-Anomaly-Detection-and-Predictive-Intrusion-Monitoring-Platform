Quick concept cards
Select a question to reveal its answer. These explain the system; they are not live detection results.

          

            
What does risk 72 mean?
A priority of 72 out of 100. For example, DDoS severity 90 × confidence 0.80 = 72, High. It is not a 72% probability of compromise.

            
Is confidence the same as accuracy?
No. Confidence is the model estimate for one prediction. Accuracy requires verified labels across examples. Current confidence estimates are uncalibrated.

            
Why can BENIGN need review?
Models may disagree or Isolation Forest may flag unusual behaviour. Review alerts are investigation leads, not confirmed attacks.

            
Does scanning train the models?
No. Scanning uses saved models. Model laboratory shows saved holdout evaluation; uploading another CSV does not change those metrics.

            
Are these live network packets?
The backend streams results while analysing stored CSV flow records. One flow can contain many packets. Live packet capture is not implemented.

            
What does TreeSHAP explain?
Contributions to one XGBoost class margin, before softmax. It does not explain policy risk, majority vote or causal responsibility.

          

          
Understand your system

          
Input: a network flow

          

            A flow summarizes a network conversation: packet sizes, counts,
            timing and rates. This application reads flow CSVs. It does not
            capture packets from your network card.
          

          
Three classifiers, one visible comparison

          

            Random Forest combines trees trained on varied samples. XGBoost adds
            trees sequentially to correct earlier errors. Extra Trees adds
            random split choices. The models use numeric features, never Label
            or IP addresses. Majority vote wins; a three-way tie uses Random
            Forest. Agreement is not proof of correctness.
          

          
Anomaly detection

          

            Isolation Forest learns benign training behaviour and flags unusual
            feature combinations. Unusual does not necessarily mean malicious.
            Anomalies create review flags and do not secretly change risk.
          

          
Risk versus confidence

          

            Risk = round(configured severity × classifier confidence). DDoS
            severity 90 × confidence 0.80 = 72/100, High. Risk is an analyst
            priority score, not a probability of being hacked. Confidence is an
            uncalibrated model estimate. Consensus confidence averages only
            models voting for the winning class.
          

          
IP evidence

          

            IPs come from supplied source and destination columns and are
            validated. Missing addresses cannot be inferred from traffic
            statistics. The original sample omits IP columns;
            cicids_demo_real_ips.csv preserves real addresses from the dataset.
            The older synthetic demonstration file is explicitly labelled.
          

          
Streaming

          

            Backend CSV → fixed chunk → off-thread inference → database →
            bounded buffer → browser. Heartbeats keep idle connections active.
            Stop prevents new reads; the current bounded inference may finish.
            Slow viewers may miss display messages, but saved result exports
            preserve processed rows.
          

          
Limitations

          

            Active models are trained on capped unique samples prepared from all
            five real CICIDS daily files. The full archive was inspected;
            training did not fit every original row. Feature-identical inputs
            stay in one partition. Independent day/session validation is still
            needed. UNSW-NB15 needs a separate schema adapter. Classification
            does not forecast future attacks. Docker packaging is included;
            cloud hosting requires your account.
