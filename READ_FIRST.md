# Read before installing TraceVigil AI

This is a complete-file update for the October 15 investigation and October 17 charts release. It preserves the original hacker stylesheet and model artifacts.

IMPORTANT: email-only login replaces username-only login. Existing sessions are invalidated. Existing users must link their email once to keep scan ownership. Real Turnstile keys, an SMTP sender and a private invitation must be configured. No keys or passwords are supplied, and there is no verification bypass. If you are not ready to configure these, keep your working version until ready.

Read docs/TRACEVIGIL_SETUP.md for all steps BEFORE copying files. Stop the server and back up your project/database. Merge complete files, install requirements and configure .env privately. Do not rename your project folder, delete models or reset the database. style.css is intentionally absent; visuals.css adds interactions in the same theme.

The Word change log is docs/TraceVigil_Change_Log_20261017.docx. Tests used mocked providers; live email, CAPTCHA, speech and Windows/browser validation remain local steps.
