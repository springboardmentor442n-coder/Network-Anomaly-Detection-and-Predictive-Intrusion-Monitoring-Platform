# Dataset directory

Drop the official **UNSW-NB15** CSV files here. The backend scans this folder
and lists any CSV it finds on the **Dataset Analysis** page (no upload needed).

```
data/
├── UNSW_NB15_training-set.csv     <- used for Model Training
├── UNSW_NB15_testing-set.csv      <- used for Model Evaluation
└── sample/
    ├── SAMPLE_synthetic_training-set.csv
    ├── SAMPLE_synthetic_testing-set.csv
    └── SAMPLE_synthetic_traffic.csv
```

## Official UNSW-NB15 files

Download from the UNSW Canberra cyber range:

<https://research.unsw.edu.au/projects/unsw-nb15-dataset>

Expected file names and columns:

| File | Rows | Purpose |
| --- | --- | --- |
| `UNSW_NB15_training-set.csv` | 175,341 | fit the model |
| `UNSW_NB15_testing-set.csv` | 82,332 | evaluate the model |

Both files contain 49 columns including the two targets:

* `label` — `0` = normal, `1` = attack  → **binary classification**
* `attack_cat` — `Normal`, `Generic`, `Exploits`, `Fuzzers`, `DoS`,
  `Reconnaissance`, `Analysis`, `Backdoor`, `Shellcode`, `Worms`
  → **multiclass classification**

`id`, `label` and `attack_cat` are always excluded from the model input
features (see `backend/app/ml/schema_utils.py`), which is what prevents
label leakage.

> These real files are **git-ignored** (`.gitignore` → `data/**/*.csv`) because
> they are large. They are never uploaded anywhere; all processing happens
> locally in the Python backend.

## Sample data — read this before quoting any numbers

The files in `data/sample/` are **synthetic**, generated by
`backend/scripts/make_sample_data.py`. They reproduce the UNSW-NB15 *schema*
so the whole workflow can be exercised without the real dataset.

**They are not UNSW-NB15 and any accuracy / precision / recall produced from
them is meaningless as a research result.** The UI labels them as sample data
everywhere they are used. Always regenerate the numbers with the real dataset
before putting them in a report.

Regenerate them at any time with:

```bash
cd backend
python scripts/make_sample_data.py
```
