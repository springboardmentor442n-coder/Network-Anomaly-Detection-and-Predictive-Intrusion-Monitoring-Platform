# CICIDS2017: Original vs Improved Version

## Why we are comparing them

The NetShield AI project uses the CICIDS2017 dataset for network traffic analysis and future machine learning work.

The mentor instructed us to understand the difference between the original CICIDS2017 dataset and the improved version.

## Original CICIDS2017

The original CICIDS2017 dataset contains network traffic collected during different activities, including normal traffic and attack traffic.

It provides labelled network traffic data for intrusion detection research.

## Improved CICIDS2017

The improved version was created after researchers examined the original dataset and identified issues related to the traffic data and its labelling.

The improved version provides improved labelling and additional information for network traffic analysis.

## Version Used in This Project

For the NetShield AI project, we are working with the improved version of CICIDS2017 as instructed by the mentor.

## Dataset Files

The improved dataset contains working-day files:

- Monday-WorkingHours.csv
- Tuesday-WorkingHours.csv
- Wednesday-WorkingHours.csv
- Thursday-WorkingHours.csv
- Friday-WorkingHours.csv
