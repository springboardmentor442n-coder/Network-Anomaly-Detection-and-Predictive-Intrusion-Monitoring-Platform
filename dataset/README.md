# CICIDS2017 Improved Dataset

This folder contains the dataset work for the NetShield AI project.

## Dataset

CICIDS2017 - Improved Version

## Files

The dataset contains network traffic data from:

- Monday
- Tuesday
- Wednesday
- Thursday
- Friday

## Purpose

This dataset will be used for network traffic analysis, anomaly detection, and machine learning in the NetShield AI project.

## Source

Improved CICIDS2017 dataset provided through the DistriNet research project.

## Dataset Files

The improved CICIDS2017 dataset contains the following working-day files:

- Monday-WorkingHours.csv
- Tuesday-WorkingHours.csv
- Wednesday-WorkingHours.csv
- Thursday-WorkingHours.csv
- Friday-WorkingHours.csv

The raw CSV files are large and are therefore kept locally rather than uploaded directly to GitHub.

## Note

The original dataset files are very large and are not uploaded directly to this GitHub repository.
