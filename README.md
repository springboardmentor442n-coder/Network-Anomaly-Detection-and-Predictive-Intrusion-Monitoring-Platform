## 🚀 Overview

**NetShield AI** is an AI-powered Network Intrusion Detection and Response platform designed to monitor network traffic, detect potentially malicious activity, evaluate security risks, and support threat investigation.

Built using Python, FastAPI, React, and machine learning, the platform provides a centralized Security Operations Center (SOC) dashboard for monitoring network activity and analyzing potential cyber threats.

NetShield AI supports **live Wi-Fi/network interface monitoring and file-based network traffic analysis**. It integrates three machine learning algorithms — XGBoost, Random Forest, and Support Vector Machine (SVM) — to classify network traffic and assist with intrusion detection.

The platform also includes security alerts, incident management, risk scoring, reports, activity history, model management, and performance evaluation.

### 🧠 4. Three-Model AI Detection Engine

NetShield AI integrates three machine learning algorithms for network traffic classification.

**XGBoost**

- Uses gradient-boosted decision trees.
- Learns complex relationships in network traffic features.
- Supports classification of normal and potentially malicious traffic.

**Random Forest**

- Combines multiple decision trees.
- Supports robust traffic classification.
- Provides a useful comparison against boosting-based approaches.

**Support Vector Machine (SVM)**

- Learns decision boundaries between traffic classes.
- Supports supervised network traffic classification.
- Can identify patterns associated with different traffic categories.

The three models can be evaluated on the same test dataset to compare their effectiveness.

## ⚙️ Quick Start — Local Setup

### Prerequisites

Install the following:

- Python 3.12.
- Node.js and npm.
- Git.
- The dependencies required by the backend and frontend.
- Any additional packet-capture utilities required for live monitoring.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
```

Replace the placeholders with your actual GitHub repository URL and project folder name.

### 2. Set Up the Backend

```bash
cd backend
python -m venv venv
```

Activate the environment on Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the FastAPI server, assuming `app.main:app` is your application entry point:

```bash
python -m uvicorn app.main:app --reload --port 8000
```

Open the API documentation:

http://127.0.0.1:8000/docs

### 3. Start the Frontend

Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local frontend URL displayed in your terminal.

Configure the frontend API URL and backend CORS settings according to your project configuration.

### 4. Docker Deployment

If your repository contains a configured `docker-compose.yml`, start the application using:

```bash
docker compose up -d --build
```

Check running containers:

```bash
docker compose ps
```

Stop the containers:

```bash
docker compose down
```

The available URLs and ports depend on your Docker Compose configuration.

## 📈 Model Training and Evaluation

The project incorporates three machine learning algorithms:

1. XGBoost.
2. Random Forest.
3. Support Vector Machine (SVM).

A consistent evaluation process helps compare their classification performance.

Recommended evaluation steps:

1. Prepare and validate the dataset.
2. Split the data into training and testing sets.
3. Apply consistent preprocessing and feature selection.
4. Train each model using the training dataset.
5. Evaluate predictions against the held-out test data.
6. Compare accuracy, precision, recall, F1-score, and false-positive rates.

Actual performance depends on the dataset, feature engineering, class distribution, and evaluation methodology. Do not publish unverified accuracy percentages.
