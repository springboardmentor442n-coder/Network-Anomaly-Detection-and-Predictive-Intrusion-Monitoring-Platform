# AI Powered Network Anomaly Detection and Threat Monitoring System

An AI-powered cybersecurity application designed to detect network anomalies, classify potential threats, predict attack risks, and support proactive network security monitoring.

## Project Overview

This project uses Machine Learning to analyze network traffic and identify suspicious activities. It helps distinguish normal network behavior from potentially malicious traffic and provides threat classification and risk assessment.

## Key Features

- AI-based network anomaly detection
- Machine Learning-based threat classification
- Attack prediction
- Risk scoring and threat assessment
- Anomaly reporting
- Web-based monitoring dashboard

## Technologies Used

- **Frontend:** React.js, Vite, CSS
- **Backend:** Python, Flask
- **Machine Learning:** Scikit-learn, Random Forest
- **Data Processing:** Pandas, NumPy
- **Version Control:** Git and GitHub

## Project Structure

- `backend/` – API, ML models, training scripts, and threat analysis
- `frontend/` – Web dashboard and user interface

## Running the Project

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```

Make sure the required Python dependencies and trained model files are available before starting the backend.

## Objective

To improve network security by identifying unusual traffic patterns, classifying potential attacks, and assessing security risks using Artificial Intelligence and Machine Learning.
